# NEON / COAST

An original single-player **3D open-world arcade racing game** for Windows and Android, built with **Godot 4.4.1 / GDScript**. Drive Meridian's coastal grid, race three rivals, earn stars and cash, and build a three-car garage. The city evokes the broad district variety of early-2000s open-world driving games; it contains no GTA maps, brands, models, music, or other third-party game assets.

## Download and play

Open this repository's [Releases](https://github.com/Mhd-Azeem/games/releases) and choose a **Neon Coast** release:

- **Windows:** download `NeonCoast.exe`, then run it. The game data is embedded, so Godot and Python are not required. Windows 10/11 x64 with an OpenGL 3.3-capable graphics driver is recommended. This executable is unsigned.
- **Android:** download `NeonCoast.apk` on an ARM64 device supporting OpenGL ES 3, allow the downloading app to install packages, and install it. The game runs offline in landscape orientation. Android 6 or newer is recommended. See the signing note below before upgrading from a previous build.

The older Three.js/Kotlin project at `../android` is separate and remains available.

## What is included

| System | Implementation |
| --- | --- |
| Open world | 560 × 560 meter drivable city, 36 independently generated blocks, road grid, waterfront, park, and collision boundaries |
| Districts | Old Quarter residential blocks, Downtown towers, Port Meridian warehouses, Sunset Beach promenade |
| Driving | Shared collision-aware arcade controller, acceleration, braking/reverse, speed-sensitive steering, lateral grip, handbrake drift, rechargeable nitro, off-road slowdown |
| Traffic | 14 vehicles following lane-offset road loops; forward obstacle sensing, corner speed control, and stuck recovery |
| Racing | Three opponents using the same controller; sequential checkpoints, countdown, position tracking, laps, finish results, timeout, and recovery penalty |
| Career | Five events, 15 collectible stars, credit rewards, three unlockable vehicles, three performance upgrades per car |
| Interface | Main menu, event board, garage, HUD, north-up minimap, three cameras, settings, multi-touch and gamepad support |
| Persistence | Versioned local JSON save, validation, temporary-write replacement, and backup recovery |
| Art/audio | Original procedural vehicles, modular city geometry, palm trees, hills, sunset sky, shadows, and synthesized engine sound |

## Controls

| Action | Keyboard | Gamepad | Touch |
| --- | --- | --- | --- |
| Accelerate | W / Up | Right trigger | GAS |
| Brake / reverse | S / Down | Left trigger | BRAKE |
| Steer | A/D / Left/Right | Left stick | < / > |
| Drift | Space | A | DRIFT |
| Nitro | Shift | B | NITRO |
| Change camera | C | Y | CAM |
| Recover | R | X | RESET |
| Pause / resume | Escape | Start | MENU / Resume |
| Career | E or menu | Menu | Menu |

Use **Free Roam** to explore. Choose **Career → Block Party** for the first race. Drive through each gold ring in order. First place awards 3 stars, second 2, third 1. Your best star result per event counts toward unlocks, while repeat finishes still earn credits. Fourth place earns a small credit reward; timing out earns nothing. Recovering during a race adds three seconds and returns you to the last cleared checkpoint. Leaving a race does not award a prize.

The garage is available from the menu. Cars require both stars and credits; owned cars can be selected freely. Performance upgrades are applied per car. Your credits, car selection, upgrades, results, and sound/graphics settings save automatically. Best progress survives restarts.

## Run from source

1. Download [Godot 4.4.1 standard](https://github.com/godotengine/godot/releases/tag/4.4.1-stable), not the .NET edition.
2. Import `project.godot` from this directory.
3. Press **F6/F5** or run `godot --path neon-coast` from the repository root.

No packages, asset downloads, or plugins are needed. All meshes and engine audio are generated by the checked-in source.

## Tests

From the repository root:

```sh
python neon-coast/tools/verify.py --godot /path/to/godot
```

This imports/parses scripts, then runs engine-level tests for career gating, purchases, upgrades, save/backup recovery, world generation, movement, braking, boost, steering, barrier collisions, traffic progress, autonomous AI race completion, checkpoint order, rewards, pause/resume, menu bounds, and simultaneous touch controls. Tests use a temporary save in `tests/` and do not touch the real career file. Script errors are treated as failures even when Godot exits with code 0.

Optional screenshots: `godot --path neon-coast --script tests/capture.gd -- --test-mode`. This requires an actual display/graphics driver and generates ignored `preview.png` and `menu-preview.png` files.

## Build and release automation

`.github/workflows/neon-coast.yml` runs on changes to this project, pull requests, manual dispatches, and `coast-v*` tags. It:

1. Installs pinned Godot 4.4.1 and matching official export templates.
2. Imports the project and runs all engine tests.
3. Configures Java 17 / Android SDK 34 and signing.
4. Exports a standalone Windows x64 EXE and ARM64 Android APK.
5. Verifies APK signing and calculates SHA-256 hashes.
6. Uploads build artifacts. Successful default-branch pushes also create `coast-build-N` prereleases; `coast-v*` tags create regular releases.

Release publishing uses the workflow's scoped `GITHUB_TOKEN` with `contents: write`; no personal token needs to be stored. Pull requests only build/test and never publish. Existing workflows and the older game are preserved. The new tag prefix avoids triggering the old game's version-tag release workflow.

### Android signing

The default APK is a **debug-signed sideload build**, so the pipeline works without private credentials. Each run creates a temporary key; to install another such build, uninstall the older one first. Uninstallation clears local career progress. This default is not a Play Store distribution setup.

For persistent release signing and updates that preserve saves, configure these **repository Actions secrets**:

- `NEON_ANDROID_KEYSTORE_BASE64`: base64-encoded private keystore.
- `NEON_ANDROID_KEYSTORE_PASSWORD`: keystore and key password (same value).
- `NEON_ANDROID_KEYSTORE_ALIAS`: signing key alias.

The workflow switches to a release-signed APK when all three exist. Never commit a private keystore or its password. Increment `version/code` in `export_presets.cfg` for subsequent Android distribution versions. Play Store publishing additionally requires an AAB and store compliance work and is outside this repository's release workflow.

### Manual exports

Install matching export templates in Godot. Configure the Java 17 and Android SDK paths in Editor Settings, following the [Godot 4.4 Android export documentation](https://docs.godotengine.org/en/4.4/tutorials/export/exporting_for_android.html). Then use the export dialog or:

```sh
mkdir -p neon-coast/build
godot --headless --path neon-coast --export-release "Windows Desktop" build/NeonCoast.exe
godot --headless --path neon-coast --export-debug Android build/NeonCoast.apk
```

## Project layout

```text
neon-coast/
  project.godot          Engine and application settings
  export_presets.cfg    Windows and Android exports
  scenes/main.tscn      Entry scene
  assets/icon.svg       Original vector launcher icon
  scripts/
    main.gd             World orchestration, race lifecycle, cameras
    city.gd             Modular districts, roads, scenery and collision
    models.gd           Reusable original mesh factories
    vehicle.gd          Shared player/AI arcade physics
    ai_driver.gd        Waypoint pursuit and obstacle handling
    catalog.gd          Editable vehicle and event definitions
    career.gd           Progression, purchases and persistent save
    hud.gd              Menus, garage, HUD and settings
    minimap.gd          Road/route/vehicle map
    touch_controls.gd   Simultaneous mobile controls
    engine_audio.gd     Procedural audio synthesis
  tests/                Headless gameplay and capture utilities
  tools/                Verification and CI configuration helpers
```

Extend the map with `Models` building factories and block templates in `city.gd`; keep roads at the 80-meter grid seams. Add events and car specifications in `catalog.gd`. All rivals and traffic use the same collision controller as the player.

## Scope and known limitations

This is a compact, complete single-player arcade game, with stylized procedural graphics rather than AAA or photorealistic assets. It has no on-foot mode, weapons, police system, interiors, multiplayer, deformable damage, or realistic drivetrain simulation. AI may queue or reverse when blocked and can recover to a waypoint after a prolonged obstruction. The city is generated at startup, with distance-culling of building visuals; it is not an infinitely streamed world. Sound is a simple generated engine tone. Mobile performance depends on the device; low graphics disables shadows and antialiasing. Build verification does not substitute for hands-on testing on physical Android hardware.
