# AZ Motion Studio 0.5.0 test build

- One-tap offline Spatial analysis and automatic enable/disable.
- Detected foreground separation, local background repair and tilt-driven perspective.
- Automatic estimated scene depth when no subject is confidently detected.
- Spatial depth controls, re-analysis and persisted/exportable configuration.
- Retains equal-size button grids, unobstructed settings preview, point multi-selection/deletion and removable recent entries.

Install the APK over the previous test build. The test package is com.az.animewallpaper.dev. Existing projects migrate automatically.

Known limits: approximate depth and background fill can show artifacts, especially around hair/occlusions. Physical sensor behavior and device-specific lock-screen wallpaper support need a real device. This is a debug-signed test build, not a production-signed release.
